# Report types

Starting points, not requirements. Each row lists what the reference mockup used. Use fewer parts when the data is thin.

| Type | Example | Type tab | Typical components |
|---|---|---|---|
| Product shortlist | NAS replacement, robot vacuum, travel laptop | Buy | Option cards with product image, cost bars, test result bars, matrix, support timeline, price per shop, bill, checklist |
| Used listings | Used hatchback | Messages | Listing cards with history chips, price vs km scatter, service record per car, questions for the seller, message blocks |
| Selling | E-bike | Negotiate | Histogram with offer and fair value, percentile lane, offer ladder (counter, settle, floor), objection verdict rows, competition list |
| Service or contract | Internet contract, car insurance | Call (Bellen) | Cumulative cost per term, tariff table, key dates list, contract terms with chips, call script |
| Money | Inflation hedge, expenses | Triggers | Allocation donut, time series with event markers, scenario payoff matrix, carry bars, trigger calendar with sparklines and gauges, rejected list |
| Travel | Portugal 2028 | Plan | Window comparison, route map, place map, nights strip, itinerary rows, flight table, stop cards, trip total bars |
| Business options | Coffee subscription, micro-SaaS | Calls | Ranked criteria (Method tab), option cards with status, criteria matrix, red-team rounds as steps, call cards |
| Feasibility | Van import, CE recertification | Route | Verdict per variant, process steps, landed-cost waterfall, blockers per variant |
| Home or DIY | Shower mixer, dishwasher | Parts | Status checklist, photo cards, parts price per shop, correction list, on-site checks |
| News digest | Today's news DE / FR / PL | Country tabs | Headline rows with image slots, country maps with pins, small multiples, citation chips. No Options, Compare or Gaps. |

## Data rules for every type

- Only figures from the sources. Derived numbers are allowed and labelled.
- If a chart needs data the sources lack, leave it out and list the gap.
- When sources conflict, show both and add the conflict to Gaps.
- Coordinates come from geocoding captured in the sources. City centres are acceptable for news pins.
- Time series come from a primary data source (for example FRED or ECB), with the capture date in Sources.
